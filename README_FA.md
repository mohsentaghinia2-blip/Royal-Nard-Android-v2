# تخته‌نرد سلطنتی — پروژهٔ اندروید نسخهٔ ۱۰٫۷

## ساختار پروژه
- `app/` — کد اندروید، صفحهٔ بازی، فایل‌های آفلاین و آیکن‌ها
- `app/src/main/java/` — کد Java برنامهٔ اندروید
- `app/src/main/assets/` — فایل HTML بازی، manifest وب‌اپ، سرویس‌ورکر و آیکن‌های وب
- `app/src/main/res/` — آیکن نصب اندروید
- `.github/workflows/` — ساخت خودکار APK در GitHub Actions
- فایل‌های `build.gradle`، `settings.gradle` و `gradle.properties` — تنظیمات ساخت

## ساخت APK در GitHub

این مخزن فقط سورس پروژه است؛ فایل APK تا زمان اجرای موفق GitHub Actions تولید نشده است.
1. محتویات این بسته را در ریشهٔ مخزن `Royal-Nard-Android` قرار دهید؛ یعنی فایل `settings.gradle` باید مستقیماً در صفحهٔ اصلی مخزن دیده شود.
2. وارد زبانهٔ **Actions** شوید.
3. گردش‌کار **Build Royal Nard Android APK** را انتخاب کنید.
4. روی **Run workflow** و سپس دکمهٔ سبز تأیید اجرا بزنید.
5. پس از پایان موفق، وارد همان اجرای workflow شوید و از بخش **Artifacts** فایل `Royal-Nard-10.7-Android-APK` را دریافت کنید.
6. فایل ZIP دریافت‌شده را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

## مشخصات
- شناسهٔ آزمایشی: `com.martivecode.royalnard.debug`
- حداقل اندروید: Android 6.0 (API 23)
- هدف ساخت: Android 15 / API 35
- چرخش آزاد صفحه، تمام‌صفحه و بدون نوار مرورگر
- فایل بازی داخل APK است و اجرای بازی پس از نصب به اینترنت یا GitHub Pages وابسته نیست.

## وضعیت کنترل کیفیت
- ساختار ZIP بررسی شد و آزمون سلامت آرشیو بدون خطا بود.
- فایل‌های اصلی پروژه و منابع بازی در بسته وجود دارند.
- APK در این محیط ساخته نشده است؛ موفقیت ساخت باید در GitHub Actions تأیید شود.
- این APK برای تست است و با کلید debug امضا می‌شود؛ برای انتشار رسمی باید امضای release و AAB جداگانه آماده شود.
